# RF Cascade Simulator

RF and baseband cascade simulator in a single page: gain, noise figure, P1dB, IP3, per-node signal
levels (dBm, dBV, Vpp), headroom, ADC check (SINAD/ENOB, NSD, noise folding) and an input power sweep.

Open `index.html` in a browser, or use the GitHub Pages link. It can be added to the iPhone home screen
(Safari → Share → Add to Home Screen) and works offline after the first visit.

Saved chains are kept in the browser (localStorage) of each device. Use **Download JSON / Load JSON**
to move chains between devices or between the claude.ai version and this one.
