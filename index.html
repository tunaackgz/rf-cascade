Input Power Sweep

Hover to read values. Click a plot to use that level as the input power.

Gain adds in dB. NF uses Friis: F = F₁ + (F₂−1)/G₁ + (F₃−1)/(G₁G₂) + … (linear). The ADC enters the cascade as a noise source with NF = PFS + 174 − SINAD − 10·log₁₀(fs/2); ENOB = (SINAD − 1.76)/6.02, ideal SNR = 6.02·N + 1.76. Clock jitter is assumed negligible.

Input P1dB and IIP3: 1/Pin = Σ Gpreceding,i / Pin,i (mW, linear). Output P1dB = input P1dB + G − 1 dB; OIP3 = IIP3 + G. IM3 per tone at a node = 3·Pout − 2·OIP3. SFDR = ⅔·(IIP3 − input noise floor). Empty P1dB or IP3 means ideal.

Sweep: the compressed curve is an estimate from the cascade output P1dB (Rapp model, p = 2); IM3 and SNDR use the small-signal intercept model. Noise floor = −174 dBm/Hz + 10·log₁₀(B) + NF + G (290 K). Sensitivity = input noise floor + required SNR. The switch on each card (and on a switched block's header) bypasses it: the part is replaced by an ideal thru so you can compare the chain with and without it.
